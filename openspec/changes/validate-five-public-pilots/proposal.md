# Validate five public cross-domain pilots

IntentLane needs evidence beyond one RSS reader before it is positioned as a
repeatable implementation offer. Validate the ASRi integration workflow on
five public, active Apple-app repositories with materially different data and
action models. Three independent successful, reproducible, in-scope pilots are
the minimum evidence gate for an offer claim; five are the target research and
validation set.

No upstream pull request or maintainer contact is implied by this change.
Those happen only after a local proof, review of each repository's contribution
rules and a maintainer-approved proposal.
