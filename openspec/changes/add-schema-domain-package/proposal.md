## Why

IntentLane only generates a limited subset of schema conformances. A complete domain package is required before selling implementation beyond audits.

## What Changes

- Adds one demand-led, schema-complete domain package with generators, adapters, validation and audit rules.

## Capabilities

### New Capabilities
- `schema-domain-package`: Complete, validated implementation of one selected App Schema domain.

### Modified Capabilities
- Aucun.

## Impact

Schema, core IR, Swift generator, fixtures, CLI audit and documentation.
