# IntentLane Expo plugin

This package contains the Expo config plugin used by IntentLane's workspace
example. It generates the native Swift output during prebuild and registers the
sources and localization resources idempotently.

The package is not published on npm. Its `0.2.0-next.0` manifest prepares a future
release under the maintainer-owned `@memolabs-apps` scope. External applications
should not add it until a tagged npm release exists.

Contributors can exercise the plugin through `apps/example-expo` in the IntentLane
repository.
