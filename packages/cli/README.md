# IntentLane CLI

IntentLane audits an existing iOS or macOS repository and generates deterministic
App Intents Swift from a versioned YAML contract.

The latest published package is `@memolabs-apps/intentlane@0.1.0`:

```sh
npm install --save-dev @memolabs-apps/intentlane@0.1.0
npx intentlane audit . --platform macos
```

This package directory on `main` is prepared for the next prerelease. Its version
and commands may be ahead of npm until the maintainer cuts a tagged release.

Read the [repository README](https://github.com/guillaume-flambard/intentlane#readme)
for the published boundary, evidence model, and contribution guide.
